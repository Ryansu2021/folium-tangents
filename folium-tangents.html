笛卡兒葉形線：曲線本身 The Curve Itself

方程式 x³ + y³ = 3axy（a 為非零常數）。此曲線有三項特徵：第一象限形成一個封閉的葉圈（loop）；沿兩個方向延伸至無窮，趨近漸近線 x + y + a = 0；通過原點，而原點是節點（曲線在此自我相交）。它不是函數（y 並非 x 的單值函數），無法直接寫成 y = f(x) — 這正是笛卡兒選它作為「刁難工具」向費馬挑戰的原因。

參數式　x = 3at1+t³，　y = 3at²1+t³，其中 t = y/x

任意點的切線方程

對 x³+y³=3axy 隱函數微分可得斜率，於是過點 (x₀, y₀) 的切線為：

y − y₀ = a y₀ − x₀²y₀² − a x₀ (x − x₀)

範例（a = 1，點 (3/2, 3/2)）：先驗證在曲線上：(3/2)³+(3/2)³ = 27/4 = 3·1·(3/2)·(3/2) ✓。斜率 = 3/2 − 9/49/4 − 3/2 = −3/43/4 = −1，故切線 y = −x + 3。

笛卡兒的方法：法圓法 Method of Normals · 《幾何學》

核心思想：圓的半徑恆垂直於圓上的切線。因此，若能找到一個與曲線在某點恰好相切（只有一個交點、即重根）的圓，那麼從圓心到切點的半徑方向，就是曲線在該點的法線方向；取其垂直方向即為切線。

操作步驟（以一般曲線 y = f(x) 為例）

1設圓心在 x 軸上，座標 (v, 0)（笛卡兒常設圓心在座標軸上以簡化計算）。
2圓方程 (x − v)² + y² = R²。
3將曲線方程代入，得到一個僅含 x 的多項式方程。
4要求圓與曲線在 P 點切觸（相切），即此多項式有重根 x = b。
5利用重根條件（可被 (x − b)² 整除）解出 v。
6法線斜率 = f(b) − 0b − v，切線斜率為其負倒數。

侷限

這個方法在曲線可寫成 y = f(x) 時運作尚可，但對於隱式方程 F(x,y)=0 的曲線 — 如葉形線 x³+y³=3axy — 代入圓方程後會產生極高次的多項式，重根條件非常難以利用。笛卡兒自己承認，他的方法只能在葉形線的頂點（x = y 對稱點）這個特殊點上奏效，無法推廣到一般任意點。這就是他自以為可以難倒費馬的原因。

頂點處的求解（本頁互動）

頂點 P = (3a/2, 3a/2) 的法線正是對稱軸 y = x，它通過原點，故圓心取在原點 (0,0)，半徑 R² = 9a²/2。此圓恰在頂點與葉圈相切（葉圈最遠點），半徑斜率 = +1，垂直得切線斜率 −1，即 y = −x + 3a。

費馬的方法：擬等法求切線 Method of Adequality · ~1636

費馬約於 1636 年完成小論文《求極大極小值的方法》（Methodus ad disquirendam maximam et minimam），其中不僅求極值，也發展出一套求切線的技術。

核心洞見：切線是割線的極限情形。在點 P = (x, f(x)) 附近取另一點 P′ = (x+e, f(x+e))，當 e → 0 時，割線 PP′ 趨近於切線。費馬使用「副切線」（subtangent）t 作為媒介：由切點 P 向 x 軸作垂線得垂足 A，切線交 x 軸於 T，線段 TA 即副切線，長度為 t。

擬等法求副切線

在小三角形 △TAP 與移位後的 △TA′P′ 之間，費馬建立「擬等式」（兩鄰點切線斜率設為近似相等）：

f(x)t ≍ f(x+e)t+e
交叉相乘f(x)·(t+e) ≍ f(x+e)·t　⟹　f(x)t + f(x)e ≍ f(x+e)t
消去 f(x)t、除以 ef(x) ≍ f(x+e) − f(x)e · t
令 e → 0（費馬稱「去掉 e」，令含 e 的項消失）
t = f(x)f′(x)

這正是微積分中的副切線公式。費馬在不自知的情況下，已經算出了導數 f′(x)。

對葉形線（隱函數微分 — 擬等法的精確等效）

對 x³+y³=3axy 兩邊對 x 微分：

3x² + 3y²dydx = 3a(y + xdydx)
(3y² − 3ax)dydx = 3ay − 3x²　⟹　dydx = ay − x²y² − ax
